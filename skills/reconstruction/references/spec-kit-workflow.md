# 可选 Spec 规划参考

Reverse Fusion Next不强制安装或执行Spec Kit。当前宿主按根docs/AGENT-WORKFLOW.md，
使用case-v2保存原话、补充、功能依据、unknown、检查、coverage及deliver。
当前宿主实现并实际比较，Craft不是执行后端，不另启模型。

用户明确选用Spec时，先核对实际安装版本及其官方帮助/模板，在当前成果项目中使用
它整理需求、计划和任务。引用原case与证据，不把Spec生成文字当成目标已观察事实，
不以任务勾选代替实际比较；继续复用同一case及完整原话。

可借鉴的审查问题：每条需求是否有依据？计划是否覆盖输入、输出、状态、错误、
服务和设备依赖？哪些事实仍未知？检查能否让错误候选失败？原话与全部补充是否覆盖？
这些问题可以直接用增强REA的feature/unknown/coverage表达，无需额外组件。

旧版强制Spec命令、Craft writer和冻结handoff规则保存在baseline/rf-1.4.0，
仅供追溯，不能作为本版安装或执行要求。
