# 日志取证与跨时区时间线

## 输入

保全原始日志及导出副本，记录摘要、设备稳定标识、采集时刻、原时区或偏移、时钟校准信息、筛选范围和导出方式。保留文件名、原始物理行号或记录 ID、原时间文本和事件语义。把来源时钟、记录写入时间及汇总时间分开。

## 判读

1. 先按目标工单、资产或业务对象筛选。以来源设备 ID 加设备内流水号定位原始事件。跨文件抄录只有在原始 ID、动作及对象可对齐时才能归并，归并后保留全部来源。不同设备的同名终端、同流水或同时间仍可对应独立事件。
2. 用明确偏移或有依据的时区规则换算 UTC，并保留原始文本。检查换算跨日、夏令时重复或缺失、偏移正负号。时区缺失、落在歧义时间且无消歧依据、或无法绑定到可信校时资料时，记录 `unknown` 或有依据的时间区间。可说明按声明偏移换算的排序及校时置信度。
3. 按绝对时间排序。并列事件保留并列，可用设备号作显示排序键。只有独立单号、确认回执或可信序列支持时才写先后或因果。单独列不可排序事件、范围外记录和覆盖缺口。

## 核对

逐条从 UTC 反算成原时间，抽查一条跨日、一条并列和一条不可排序记录。复核 `原始行数 → 归并映射 → 业务事件数`，将排除项的原事件编号与排除依据列清。导出时间和事件时间分开。若结论为某动作未见，写明实际覆盖的设备和时段。

## 反例

`2026-11-19T08:03:10+08:00` 与 `2026-11-18T19:03:10-05:00` 均换算为 `2026-11-19T00:03:10Z`。两台设备分别记录“交出”和“接收”时保留两条。导出表抄录其中一条时合并来源。第三条时间只有本地 HH:MM:SS 且缺偏移，应保留为未定位的事件。
