# 输入和结果

给工具传入用户指定的本地普通文件。记录文件摘要和观察范围。对 ZIP 资源包，内容摘要按成员计算，可区分同名已修改、增加和消失。比较空的声明清单时仍要核对原始对象 ID。

Android 发行件从实际 APK 的编译清单读取包身份和声明权限。普通文字清单只能支撑文字本身的内容。PE 或 ELF 的可见头字段只说明文件格式和架构。HTML、扩展清单、SQLite、抓包和本地观察文档分别按材料实测范围解释。

`review_summary` 和 `review_compare` 读取现有 REA 结构的导出。需要正式证据身份和官方接受结果时请取实际官方返回。自有读取、宿主推断、官方观察与程序行为应指向各自的来源。

`field_rea_identify` 接收不大于 64 KiB 的本地 UTF-8 XML 属性列表，调用固定官方 `inspect-artifact` 并重新导入该次新导出。返回原导出字节的 Base64、摘要、证据编号及导入回执。二进制 plist 由 `field_observe` 读取其中的包信息。

需要交付可重导的档案时，将 `official.bundle_base64` 解码为原始字节保存，核对 `bundle_sha256`，把原件名、原件摘要和证据编号一并交给接收方。下一步可将保存的路径交给 `review_rea_import` 或与另一份档案一起交给 `review_rea_compare`。临时目录的路径只记录当时的执行环境。失败结果中的 `partial_export` 表示已取得并核对来源的导出，重导仍未验证。已有的官方命令回执保留退出码及输出流原始字节的 Base64。
