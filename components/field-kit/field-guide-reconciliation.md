# 跨材料对账与证据归属

## 输入

收集决定口径的公告或规则、当前主数据、可追溯的原始流水和用户期望产物。记录截点和时区、对象粒度、能连接的稳定键、快照版次、单位与数据覆盖。若同时涉及配置、日志或批次，按领域索引选对应方法补关键判读。

## 判读

1. 先写出规则和统计口径，再决定各来源能证明什么。例：公告给目标和截点，现装清单给当前对象及批次，流水给事件和已入账状态。连接键可以是 `对象 ID + 批次 + 班次` 或 `设备 ID + 事件号 + 时段`，展示名或相同数量仅作线索。检查重复键、缺失键和一对多关系，避免连接放大。
2. 将每条目标记录归入 `确认计入 / 确认排除 / 待核`。记录原 ID、输入文件行、时间、数量和判断依据。只累计符合适用状态、批次、时间及口径的记录。冲销或更正按规则和原记录关联。分开汇报确认值、待核值及其可能影响，未知分支给出还缺哪份原始记录。
3. 区分“现有资料是否足以证明达标”与“截止时点实际是否达标”。明确回答各自的问题。报告和图表由同一份带证据引用的台账生成，节点与关系保留稳定 ID 及方向。

## 核对

逐对象复核目标、确认数量、差额和待定数。检查资料权威、截止边界、非目标事件与旧批次。回读保存后的结构化表和报告，确保数据类型、编号、单位以及每个证据引用一致。图表应能回读真实节点、连线、方向和来源编号。

## 反例

目标为 6 件，截点已确认同批入账 2 件，另 4 件的批次字段空。当前材料不足以证明达标，实际是否达标为 `unknown`。截点之后确认入账的同批 4 件属于期后记录。若公告包含截止瞬间，恰好到点且满足其他条件的记录计入。
