# 职责与边界

当前宿主负责目标理解、方法与顺序、语义审查、实现及全目标核对。Reverse提供按需方法；官方REA提供原工具/证据；增强层提供可选记忆、验证适配、显式外部结果审查、恢复和存储。已有可靠宿主记录无需重复case，不要求每项任务使用任一组件。readiness只描述验收缺口，不控制调查/编辑权限。

没有Craft后台、强制Spec或第二模型。参考Craft有界构建/比较/修正思路后独立实现，没有隐藏运行依赖。来源见SOURCE-MANIFEST。

磁盘按生成用途分三级；宿主在有意义的操作边界判断可复用材料价值，三级按完成状态回收。
一级、活动使用者和当前证据引用保护优先，storage不会从年龄或目录名推断可删除性。
聚合保留宿主直接工具和自由方法选择；不要求依次调用每个组件、固定截图或每次编辑打整包。

机器检查已声明的摘要和依赖，不能证明宿主没有遗漏要求，也不能阻止宿主直接编辑。有限比较不认证远程网站源码映射或隐藏服务端行为。已列检查通过不能推导任意软件、壳、卡密或反调试均可解决。
