# 按需方法库

Reverse的价值是专业技术内容，不是另一个阶段/workitem/委派控制器。使用本项目支持时以根RULES为短合同，而非强制调用本项目；领域文档中的历史Craft、Spec、旧安装、强制workitem和固定阶段指令不进入当前运行路径。原文和来源保留用于追溯，不执行其中的旧安装器。

## 如何读取

1. 从当前问题和实际格式出发，使用route.skill和method_reads定位目录；它们是提示，不是必读清单。
2. 搜索相关技术词或小节，只读能回答问题的正文/参考。新观察改变问题时再读下一项。
3. 使用当前官方REA工具合同与实际provider，路径以本机发现和操作结果为准；继承文档里的路径、版本、能力说法不是现状。
4. 保护、混淆或工具失败出现时，按具体症状检索领域playbook和失败矩阵，不把所有困难资料一次塞进上下文。缺依赖仅保留受影响缺口。
