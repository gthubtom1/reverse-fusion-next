# 维护恢复入口

这是我们自己的融合项目。REA 是主要工具和证据核心，Reverse Skills 提供按需读取的领域方法，Craft 贡献独立对照、发现差异和修正成果的方法，SEEP 提供选定的专项能力。用户决定要什么成果，宿主智能体根据任务自行选择工具、方法和顺序。每次恢复工作，先核对这个目标，再接着处理上次留下的具体缺口。

`fusion.py` 是 Windows x64 四方融合源码入口，`field.py` 仍是 Field 1.1.19 入口。融合源码已通过本地四方交接测试：按需方法、同一制品的两类证据、独立运行与修正复验、跨连接续接。真实助手自主选用及相对裸助手效果仍未验收，日常安装未切换，旧 ZIP 不含本轮功能。[用户入口](../../README.md) · [功能实测](FUSION-CANDIDATE.md)

Field 的安装范围及历史边界见[旧快照说明](../../release/field-scope.md)。[状态](STATUS.json)区分候选与此前交付。
