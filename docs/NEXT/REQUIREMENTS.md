# 需求与完成判据

以下保留历次约定的原文。文中的“当前实施只做静态校验”指 2026-11-18 当时的验证范围。每次发行实际完成的部分见[现行交付入口](../../README.md)。

2026-11-18最终形态补充（覆盖下表中被理解成强制操作顺序的表述）：宿主自主选择工具、方法与顺序，本项目是可选支持。已有可靠记录无需重复case；readiness只诊断验收，不限制调查或编辑。外部专业观察可以走独立标注的宿主审查，不自造内部pass或官方proof。输出类型依据用户原话约定，独立重写、按规格实现、分析与修改原程序分别表达。当前实施只做静态校验，运行/部署/模型效果不自动继承旧资格。
